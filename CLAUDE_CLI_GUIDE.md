## ⌨️ Горячие клавиши

| Клавиша | Действие |
|---------|----------|
| `ESC ESC` (двойное нажатие) | Очистить ввод |
| `Shift + Tab` | Автоматически принять редактирование |
| `Ctrl + _` | Отменить последнее действие (undo) |
| `Ctrl + Z` | Приостановить сессию |
| `Ctrl + O` | Подробный вывод (verbose) |
| `Ctrl + T` | Показать todo-list |
| `Ctrl + V` | Вставить изображения |
| `Tab` | Переключить режим thinking |
| `\ + Enter` | Новая строка в вводе |

## 💬 Специальные команды

### `/` - Команды системы

```
/help              - Справка
/clear             - Очистить экран
/reset             - Сбросить контекст
/tokens            - Показать использование токенов
/model             - Информация о модели
```

### `@` - Работа с файлами

```
@путь/к/файлу      - Указать файл в контексте
@.                 - Текущая директория

Примеры:
  "Покажи @config/settings.py"
  "Отредактируй @core/detector.py"
```

### `#` - Запоминание (memorize)

```
# Важный факт     - Запомнить информацию

Примеры:
  "# Используем CUDA 12.1"
  "# База данных: icam2, пароль: icam2password"
```

### `!` - Bash режим

```
! для входа в bash режим

В bash режиме можете выполнять команды напрямую:
  ls -la
  git status
  python script.py
```
